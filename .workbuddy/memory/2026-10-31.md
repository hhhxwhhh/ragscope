### 关键约定（后续改动请遵守）

- 检索只有一个入口 `app/rag/pipeline.retrieve()`；单轮/Agent/深度/MCP/public 全部复用它，
  否则指标与 trace 口径会分叉。
- 多智能体图只决定「收什么证据」，最终回答永远走 grounded Prompt，保证引用编号与
  `citation_stats` 三种模式一致。
- MCP 与 `/public/*` 只读；写操作只在 Web 端。
- 后端指标标签必须用路由模板，禁止裸路径。
- 图扩展的候选追加在重排结果之后，不参与重排排序。

### 环境限制（重要）

- 本机无法访问 PyPI（pip 502），因此指标层与 MCP 协议层是手写实现，不引第三方包。
- 本机无 Docker；本地 PostgreSQL/Redis 服务存在但凭据未知，集成测试无法运行。
  验证方式：ruff、`import app.main`、httpx ASGITransport 打 `/metrics` 与 `/mcp`、
  用真实 DeepSeek 跑通一次 `stream_deep`（planner 4 子问题 + 1 轮 critic 判定 sufficient）。
- 运行完整测试需要用户自己的 PostgreSQL/Redis（`make dev-db` 或本机服务）。
